渠道测试报告与尾货数据自动生成，超期数据自动生成小程序上线，安装与使用方法如下

①安装
新建一个文件夹，将安装报解压到新文件夹中。
解压后首先运行python 3-12-3安装程序

注意勾选添加python到系统路径选项，勾选后点击 Install Now

python安装完成后，点击，安装.bat 程序，等待软件包下载完成，结束后即可正常运行软件


②运行
点击运行程序

第一次运行需要输入名字与工号，每输入一行按回车进入下一步

超期会自动检索系统近15天的订单，并筛选掉不处理的渠道和测试订单，与现有超期文件计算逻辑相同，省去人工导出步骤

如果需要新增不处理的渠道，可自行在资源文件夹中修改 Exclusion channels for overdue orders.xlsx表格

渠道测试，只需要输入需要导出的时间和渠道名称，就可以自动生成目前渠道测试报告所需的全部数据，并存储在文件输出文件夹中
